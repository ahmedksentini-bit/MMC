Formulaire

Toutes les formules du cours.

Déformations (ch. 2)

\(\varepsilon_{ij}=\tfrac12(u_{i,j}+u_{j,i})\quad \omega_{ij}=\tfrac12(u_{i,j}-u_{j,i})\)
\(\gamma_{xy}=2\varepsilon_{xy}\qquad \theta=\mathrm{tr}\,\boldsymbol\varepsilon=\Delta V/V\)
\(\varepsilon(\alpha)=\varepsilon_{xx}\cos^2\alpha+\varepsilon_{yy}\sin^2\alpha+\gamma_{xy}\sin\alpha\cos\alpha\)
rosette : \(\gamma_{xy}=2\varepsilon_{45}-\varepsilon_0-\varepsilon_{90}\)
thermique : \(\boldsymbol\varepsilon_{th}=\alpha\Delta T\,\mathbf I\)

Contraintes (ch. 3)

\(\vec T=\boldsymbol\sigma\cdot\vec n\quad \sigma_n=\vec n\cdot\boldsymbol\sigma\cdot\vec n\quad \tau=\sqrt{|\vec T|^2-\sigma_n^2}\)
équilibre : \(\sigma_{ij,j}+f_i=0\)
\(I_1=\mathrm{tr}\,\boldsymbol\sigma\quad p=I_1/3\quad \mathbf s=\boldsymbol\sigma-p\mathbf I\quad q=\sqrt{3J_2}\)
\(q=\sqrt{\tfrac12[(\sigma_1-\sigma_2)^2+(\sigma_2-\sigma_3)^2+(\sigma_3-\sigma_1)^2]}\)
\(\tau_{max}=\tfrac12(\sigma_1-\sigma_3)\)

Cercle de Mohr (plan)

\(C=\tfrac12(\sigma_{xx}+\sigma_{yy})\quad R=\sqrt{\left(\tfrac{\sigma_{xx}-\sigma_{yy}}2\right)^2+\sigma_{xy}^2}\)
\(\sigma_{1,2}=C\pm R\qquad \tan2\theta_1=\dfrac{2\sigma_{xy}}{\sigma_{xx}-\sigma_{yy}}\)
\(\sigma_n=C+\tfrac{\sigma_{xx}-\sigma_{yy}}2\cos2\theta+\sigma_{xy}\sin2\theta\)
\(\tau=-\tfrac{\sigma_{xx}-\sigma_{yy}}2\sin2\theta+\sigma_{xy}\cos2\theta\)

mêmes formules pour \(\boldsymbol\varepsilon\) avec \(\varepsilon_{xy}=\gamma_{xy}/2\)

Élasticité isotrope (ch. 4)

\(\boldsymbol\varepsilon=\frac{1+\nu}E\boldsymbol\sigma-\frac\nu E\mathrm{tr}(\boldsymbol\sigma)\mathbf I+\alpha\Delta T\,\mathbf I\)
\(\boldsymbol\sigma=\lambda\,\mathrm{tr}(\boldsymbol\varepsilon)\mathbf I+2\mu\boldsymbol\varepsilon\)
\(\varepsilon_{xx}=\frac1E[\sigma_{xx}-\nu(\sigma_{yy}+\sigma_{zz})]\qquad \gamma_{xy}=\sigma_{xy}/G\)
\(G=\frac E{2(1+\nu)}\quad K=\frac E{3(1-2\nu)}\quad \lambda=\frac{E\nu}{(1+\nu)(1-2\nu)}\)
\(w=\tfrac12\boldsymbol\sigma:\boldsymbol\varepsilon=\frac{p^2}{2K}+\frac{q^2}{6G}\)
bloqué : \(\sigma=-E\alpha\Delta T\) (barre), \(-\frac{E\alpha\Delta T}{1-\nu}\) (dalle)

États plans

contraintes planes : \(\sigma_{zz}=0\), \(\varepsilon_{zz}=-\frac\nu E(\sigma_{xx}+\sigma_{yy})\)
déformations planes : \(\varepsilon_{zz}=0\), \(\sigma_{zz}=\nu(\sigma_{xx}+\sigma_{yy})\)
\(E'=\frac E{1-\nu^2}\quad \nu'=\frac\nu{1-\nu}\) (déf. planes)

Solutions classiques (ch. 5)

traction : \(\sigma=\frac NA\quad \Delta L=\frac{NL}{EA}\)
flexion : \(\sigma=-\frac{My}I\quad \kappa=\frac M{EI}\quad I_{rect}=\frac{bh^3}{12}\)
torsion : \(\tau=\frac{M_tr}J\quad \alpha=\frac{M_t}{GJ}\quad J=\frac{\pi d^4}{32}\)
Lamé : \(\sigma_r=A-\frac B{r^2},\ \sigma_\theta=A+\frac B{r^2}\) ; \(A=\frac{p_aa^2-p_bb^2}{b^2-a^2},\ B=\frac{(p_a-p_b)a^2b^2}{b^2-a^2}\)
Boussinesq : \(\sigma_z=\frac{3P}{2\pi}\frac{z^3}{R^5}\) ; plaque : \(\sigma_z=q\left[1-\frac{z^3}{(a^2+z^2)^{3/2}}\right]\), \(s_0=\frac{2(1-\nu^2)qa}E\)
Kirsch : \(\sigma_\theta=\sigma_\infty(1-2\cos2\theta)\) au bord, max \(3\sigma_\infty\)
Odemark : \(h_e=0{,}9\,h_1(E_1/E_2)^{1/3}\)

Critères (ch. 6)

Tresca : \(\sigma_1-\sigma_3\le\sigma_e\)
von Mises : \(q\le\sigma_e\) ; plan : \(\sqrt{\sigma^2+3\tau^2}\le f_y\)
Rankine : \(\sigma_1\le f_t\)
Mohr-Coulomb : \(\tau\le c+\sigma'_n\tan\varphi\)
\(\sigma_1=\sigma_3K_p+2c\sqrt{K_p}\), \(K_p=\frac{1+\sin\varphi}{1-\sin\varphi}\), rupture à \(45°+\varphi/2\)

Vers la RDM (ch. 7)

\(N=\int\sigma_{xx}dA\quad M_z=-\int y\sigma_{xx}dA\quad T_y=\int\sigma_{xy}dA\)
\(\sigma_{xx}=\frac NA-\frac{M_zy}{I_z}\qquad \tau=\frac{TQ}{Ib}\)
\(\frac{dT}{dx}=-p\qquad \frac{dM}{dx}=T\)
\(\sigma_{1,2}=\frac\sigma2\pm\sqrt{\frac{\sigma^2}4+\tau^2}\quad \tan2\theta=\frac{2\tau}\sigma\)
